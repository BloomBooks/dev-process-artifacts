What this PR is about

Problem

With the UI language set to French, the Edit tab's top bar is noticeably taller than in English, a 6.5 regression that 6.4 did not show. The "Book and Page Settings" button's French label, "Paramètres du Livre et de la Page", wraps onto three lines and pushes the whole bar down.

Cause

The button was fixed at 88px wide with a freely wrapping label. In 6.5 the top bar is a single React flex row whose height follows its tallest child, so a three-line label grows the bar. In 6.4 the same wrapping happened, but the bar lived in a fixed-height WinForms-hosted browser that hid it.

What the PR does

A CSS-only change to the Book and Page Settings button in BookSettingsButton.tsx:

  • The button may now widen, from 88px up to 124px, so long translations (French, Portuguese) fit on two lines.
  • The label is clamped to two lines with an ellipsis as a backstop, so no translation can ever change the bar's height.
  • English now reads "Book and Page" over "Settings" in a slightly wider button. The bar height is unchanged, 71px in both English and French, measured in a running Bloom.

Decisions

The English label now wraps differently. Before this change the English button read "Book and" over "Page Settings" in an 88px-wide button. Because the button now grows up to 124px so that French fits on two lines, the English label also spreads out and reads "Book and Page" over "Settings". The bar height is identical either way. The only way to keep English pixel-for-pixel as before is to keep the button at 88px and let French end in an ellipsis ("Livre et de la…"), which is worse for French and Portuguese users.
