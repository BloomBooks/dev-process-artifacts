If Crowdin prunes translations for ids we removed, the safety net we keep citing isn’t there.

Devin · Investigate · new this round · thread open

Three times now — in the commit message, the PR description, and the reply on Devin’s first thread — this work has reassured the reader that deleting an English entry is recoverable, because the other roughly forty language files still hold the entry, so re-adding the id would pick its translations back up.

Devin’s re-review questions whether that stays true: “…it means the next Crowdin handoff may prune those targets, at which point the recovery path described in the PR is gone. Anyone who wants the escape hatch to stay open should confirm how the handoff treats ids absent from en.”

I can’t settle this from the repository — whether the sync deletes target entries whose id has vanished from the English source is a property of the Crowdin workflow, not of anything checked in, so I haven’t tried to answer it by reading code.

It matters beyond this PR. The same reassurance justified commit 901bf1f333, which deleted 39 entries. If the handoff does prune, then “the translations are still there if we need them” isn’t a safety net for any of those — it just means nothing has needed to fall back on it yet. If it doesn’t prune, this is a non-issue and the thread can be closed.

FYI — I could not carry out “revert the incidental re-wrapping”

Your round-1 answer · blocked, not skipped

You asked me to revert the 45 lines of re-wrapping in The Moon and the Cap. I did not, because it cannot survive a commit and I did not want to spend a commit proving that.

The cause is src/content/package.json, whose lint-staged config is {"*": "prettier --write"} — every staged file under src/content gets reformatted on commit. And prettier --check passes on the re-wrapped file, so that form is prettier’s canonical output: master’s copy was simply never formatted. Reverting the whitespace and committing therefore re-applies it.

Making it stick needs a .prettierignore in src/content excluding the shipped sample books — a change to shared tooling affecting everyone who edits those files, which felt beyond a card about string entries. The alternative I did not take was bypassing the hook, which I won’t do unasked.
