What this PR is about

Problem

The new React Collection Settings dialog still showed a placeholder on its Advanced page, so a user could not turn automatic updating on or off or rename the collection there, which the old WinForms dialog allows.

What the PR does

  • A real Advanced page with Program › Automatically Update Bloom and Collection › Collection Name. Saving and renaming go through the shell's existing settings properties; a name change turns OK into Restart.
  • Since the save stores exactly what it is sent, the dialog trims any text the user edited, on any page, before deciding on Restart and before saving: spaces typed around a collection name are not a rename, and no folder gets a name ending in a space. Values the user did not touch go back exactly as loaded.
  • In a Team Collection the name is greyed out with the old dialog's explanation underneath, faded with the row like any disabled Config-R row's description.
  • Three new strings in BloomMediumPriority.xlf, marked translate="no"; the other labels reuse existing ids.
  • Unit tests, and an e2e journey test that saves auto-update and renames the collection through Restart. For that, a Bloom started for automation passes its launch options on when it relaunches itself (as it does to finish a rename), the renaming copy waits for the old Bloom to exit, and the e2e fixture follows the relaunched copy.

What changed this run

Acted on John Thomson's Reviewable comments: the dialog now trims once and gives the same trimmed values to the Restart check and to the save, the parameter is renamed valueWhenOpened, and the comments say what each part does. We kept trimming only what the user edited, rather than everything. If every value were trimmed, a Team Collection whose name has spaces around it would be renamed even though its name cannot be edited, and settings that are never saved would stay untrimmed anyway. Each of John's four threads has a reply. Also guarded the Restart label against a change that arrives after the dialog has closed (found by the local review).
