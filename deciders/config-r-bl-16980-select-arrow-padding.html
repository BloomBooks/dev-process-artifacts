What this PR is about

Problem

In a ConfigrSelect, a choice long enough to set the dropdown's width runs under the down arrow. Bloom hit this in Book and Page Settings with French labels (BL-16958).

Cause

The select's padding: 3px !important shorthand also set the right padding to 3px, overriding the 32px MUI keeps on the right for the arrow. Short choices hid it, because the select's 180px minimum width leaves room anyway.

What the PR does

Sets the padding as 3px 32px 3px 9px !important: the same top, bottom and left as before, with MUI's 32px restored on the right (lib/ContentPane.tsx:958). A select with a long choice gets about 29px wider. Short choices are unchanged.
