What this PR is about

Problem

In the Canvas tool, a color bar (Text, Background or Text Outline Color) shows "Default for style" when that color hasn't been changed. In languages with a longer translation, such as French, the label wraps onto two lines and the second line spills out past the bar's border. This goes back to at least 6.3.

Cause

The row that holds the swatch and the label had a fixed height of 17px, so a second line had nowhere to go.

What the PR does

  • The fixed height is now a minimum height with 4px of padding above and below, so the bar grows when the label wraps.
  • A 6px right margin keeps wrapped text off the border. The label's line height is a little tighter.
  • The swatch keeps its size next to wrapped text.

English looks the same as before: the label still fits on one line, and the bar keeps its usual height. colorBar.tsx:78–127
