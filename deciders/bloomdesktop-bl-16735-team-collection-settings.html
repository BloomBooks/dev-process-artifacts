What this PR is about

Problem

The new React Collection Settings dialog (BL-16271) showed only a placeholder on its Team Collection page. Users still had to use the old WinForms dialog to see a Team Collection's shared folder, edit its administrators, or turn a collection into a Team Collection.

What the PR does

  • The page reuses the old tab's panel, including the experimental warning and the subscription overlay. The WinForms tab and its Create dialog work as before.
  • Administrators are kept by the dialog, like the subscription code. When the user edits them, they are checked in the browser using the rule C# uses, so a bad list shows an error in the field and disables OK. A change is saved through ApplyAdministrators and needs a restart, as in the old dialog.
  • Creating a Team Collection waits for OK (PLAN Q12). "Create a Team Collection" opens the existing Create dialog in the browser, and its OK only hands the folder back. On the settings dialog's OK, C# saves the settings first and then creates the Team Collection, under the Team Collection subscription rules (no Pro code). Then Bloom restarts. Cancel abandons it.
  • The page is hidden when the feature is off (as saved) and this is not a Team Collection, and for a Bloom Library book downloaded for editing.

Renaming and creating a Team Collection in the same save

In the new dialog, a user could rename the collection on the Advanced page and also choose "Create a Team Collection" before pressing OK. On save, Bloom creates the Team Collection immediately, under the old name: the shared folder is named "<old name> - TC" and the link file is written in the old local folder. The rename only moves the local folder as Bloom closes for the restart. The result is a Team Collection named for the old collection, linked from a folder that has moved. Devin found this (thread, left open). The old dialog could not do both, because its Create restarted at once.

The Create checklist also asks the user to approve the name it shows, which is still the old one if they have just renamed.
