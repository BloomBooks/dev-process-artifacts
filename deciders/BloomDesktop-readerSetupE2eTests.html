Set Up Levels can stop working after the new Stages dialog is cancelled

The coexist test opens the new React "Set Up Stages" dialog, presses Cancel, then presses "Set Up Levels" on the Leveled Reader tool. About half the time the Levels dialog never appears. The screenshot shows the button pressed and nothing opened, and Bloom never makes the dialog's first request.

I checked whether the cause is the test or Bloom. With the same setup but without opening and cancelling the Stages dialog, the Levels dialog opened 5 times out of 5, and it also did with only the Leveled tool enabled. So something the Stages dialog leaves behind seems to stop the legacy dialog opening. That code is already merged in #8132 and is on master. I have not found the root cause.

How to tie these tests to the Notion test inventory?

The e2e procedure asks that every automated test appear in the Notion "Test Case Runs" inventory, with its Test Case ID in the test's title. None of these do yet, and neither does the journey test that merged with #8132. Existing manual cases overlap in part, notably TC 427 (Build a Spanish Decodable From Scratch), TC 429 (Set Up Stages Sources) and TC 446 (Allowed Words Define Stages). The procedure says a card a test only partly covers must be split into automated and manual portions.
