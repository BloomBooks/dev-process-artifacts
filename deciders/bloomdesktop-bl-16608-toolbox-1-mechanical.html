What this PR is about

Problem

toolbox.ts does two unrelated jobs. It manages the Edit tab's toolbox, and it also holds about 460 lines of page-editing machinery that keeps a tool's markup intact while the user types, pastes and undoes: reader-tool highlighting and Talking Book sentence spans. It also carries code that nothing reaches. This is the first of three PRs that retire the legacy toolbox infrastructure (BL-16608). It is the part with no behavior change, so it can be reviewed quickly and land first.

What the PR does

  • Moves the page-editing markup engine verbatim from toolbox.ts into a new pageEditingMarkup.ts. The toolbox hands itself to the engine when it installs the text-box handlers, so the dependency runs one way. The only edit inside the moved code is that it asks the toolbox for the current tool (pageEditingMarkup.ts:402). Until the toolbox has handed itself over, that counts as "no current tool", as before. The spec moves with the code.
  • Deletes code nothing reaches: unreachable functions, flags nobody reads, tool-contract members that do nothing, and ToolboxRoot's legacy-HTML machinery, which nothing ever assigned.

To review the move, git diff --color-moved=zebra shows pageEditingMarkup.ts as moved blocks. Until the other two PRs are up, #8109 shows the whole refactor in one diff.
