What this PR is about

Problem

A contributor "Ana López" did not resolve to a person whose name field is " Ana López ", and an NFC "José Núñez" did not resolve to the same name stored decomposed (NFD), as names arrive from macOS file systems. They showed as missing people and were exported without the person's details.

Cause

Person references were compared by lower-casing only, in several places each with its own comparison.

What the PR does

  • One function, personReferenceKey (NFC, trimmed, lower case), decides whether two references name the same person.
  • Every comparison uses it: finding a person for a contributor (and so every export and check), the IMDI preview's missing-person list, renaming references, a person's contribution list, merging contributions, SayMore participants, and the check that stops two people having colliding ids.
