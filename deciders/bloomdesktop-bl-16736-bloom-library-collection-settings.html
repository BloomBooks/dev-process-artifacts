What this PR is about

Problem

The new React Collection Settings dialog (the Settings button beside Old Settings) still showed a placeholder on its Bloom Library page. That page should hold the collection's Bloom Library bookshelf, which today is only on the old dialog's Book Making tab.

What the PR does

  • The page: a "Bookshelf" select listing None plus the bookshelves that the collection's subscription has on Bloom Library, with the Enterprise subscription badge. The list is disabled when there is nothing to choose. If Bloom Library can't be reached, the page says so, and the saved bookshelf stays in the list.
  • Fresh on every open: the dialog stays mounted between opens, so the list is fetched again each time it opens. Without that, a later open kept the first open's list, or its failure to reach the server.
  • Saving: the bookshelf is now one of the collection/settings values ("" for none), saved on OK with everything else. Changing it still needs a restart, as in the old dialog, because open books carry the bookshelf.
  • Expired subscriptions (BL-15056): Apply still runs the subscription-and-bookshelf rule after the posted values are in, so a bookshelf remembered for an expired subscription stays in the file.
  • Strings: Common.None (Bloom.xlf) and two bookshelf strings (BloomMediumPriority.xlf), all translate="no". The two commented-out bookshelf entries in en/Bloom.xlf, which were never translated, are gone.
