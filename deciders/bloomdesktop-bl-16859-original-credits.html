What this PR is about

Problem

When a book is a derivative, Bloom generates a sentence on the credits page about the original book's copyright and license, and the user cannot change it. Some publishers need different wording.

What the PR does

A padlock in that sentence's hint bubble turns it into an ordinary editable field holding Bloom's wording. From then on Bloom shows what the user typed instead of generating the sentence.

  • The unlock lasts for one rendering of the page. Refreshing, leaving the page, or clicking the open padlock brings back the read-only sentence with the user's words.
  • The user's wording lives in the data div under a new key, userOriginalCopyrightAndLicense, and having it is what stops Bloom generating the sentence. There is no meta.json flag. The key is new because Bloom versions before mid-2017 stored the generated sentence under originalCopyrightAndLicense.
  • Emptying the field brings Bloom's sentence back, with the padlock.
  • The book stays a derivative: the original copyright, license URL and notes are untouched, and "Not a translation or new version" hides the user's wording as it hides Bloom's.
  • Hint bubbles gain an icon link (data-link-icon, data-link-target, data-link-icon-tooltip), and the two epub selectors accept either shape of the sentence.
