What this PR is about

Purpose

Bloom needs to show the languages of a text cell beside Content Type in all four table menus (Cell, Row, Column, Table), and needs that setting to follow a cell wherever the library copies cell settings. bloom-table knows nothing about languages, so this PR gives a host two general hooks for it.

What the PR does

  • setHostMenuSectionProvider lets a host add a section of its own directly after Content Type in each of the four menus. The host answers with a React element, which the library renders: as a child of the Cell menu's React tree, and in a React root of its own in the Row, Column and Table menus. After every content-type choice the library asks again and mounts the new element afresh, so the host's controls start from the cells as they now are.
  • An open menu moves itself back inside the window whenever its size changes, so a section that grows cannot push the menu's last commands below the window.
  • setHostCellSettings lets a host's own per-cell setting travel with the library's: into new rows and columns, through Paint format, and through Copy / Paste properties. A source cell with no setting clears the target's.
  • The Cell menu's rows use the other menus' type size, padding and label indent, so every label in the four menus starts the same distance in.
