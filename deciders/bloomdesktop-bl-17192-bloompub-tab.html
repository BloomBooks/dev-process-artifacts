What this PR is about

Problem

The nightly's BloomPUB image-resolution test failed in "Set the BloomPUB resolution to Full HD" with an error saying the Book and Page Settings dialog has no page "BloomPUB", while listing BloomPUB among the pages it offers.

Cause

The helper waited only for the dialog's first tab, then counted the tab named exactly "BloomPUB" once. Tab names are localized asynchronously, and the BloomPUB page shows its code default "eBooks" until the translation arrives, so on a slow runner the count came back 0. The fault is in the test: Bloom may show the dialog before every translation has arrived.

Fix

The helper now waits up to 10 seconds for exactly one tab with the page's name. If none shows in that time, it fails saying so and lists the tabs the dialog offers at that point. Only src/BloomE2E/helpers/bookSettings.ts changes.
