What this PR is about

Problem

In a ConfigrSelect dropdown, an option with a description shows it in a tooltip when you point at the option's label. If you then moved the pointer down the list, the tooltip stayed open on top of the options below it. Bloom users meet this in Collection Settings, in the Bloom Library page's Bookshelf list.

Cause

MUI's tooltip is interactive by default: the pointer can move onto the popup and it stays open. The option tooltip opens just below the label, over the next options, and the 14px gap above it counts as part of the popup. So moving down off a label put the pointer straight onto the tooltip, which kept it open.

What the PR does

  • Adds disableInteractive to the option's tooltip (lib/ContentPane.tsx:1006), so it closes as soon as the pointer leaves the label. It still opens on hover, keyboard focus and touch.
  • Gives two more Front/Back Matter Pack options descriptions in the Bloom collection story, so Storybook has neighbouring options with tooltips to check this by hand.
