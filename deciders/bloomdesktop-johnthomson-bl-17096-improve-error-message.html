What this PR is about

Problem

When someone bulk uploads a Team Collection, every changed book that they have not checked out fails with “Tried to save a non-editable book.” That message doesn’t tell them what to do. Ian Hodgson had 12 of 14 books fail this way and had to ask support to find out that he needed to check them out first.

Cause

Bulk upload saves each book before it uploads it. A Team Collection allows that save only for a book that is checked out here, so a guard in the save stops it and the uploader passes the guard’s message on as it is.

What the PR does

  • Once bulk upload knows a book needs uploading, it checks whether it may save that book. If not, the log says the book “was not uploaded because it was not checked out to you,” using the wording suggested on the card, with no stack trace. The book still counts toward the “Failed to upload N books” total.
  • Unchanged books are still skipped before this check, checked out or not.
