What this PR is about

Problem

A Thai user clicking OK in Collection Settings got a crash (a NullReferenceException in XMatterPackFinder.GetValidXmatter). The same user's log also showed missing page-list thumbnails.

Cause

The user's Windows regional format is Thai (th-TH). IndexOf, LastIndexOf and EndsWith compare using the current culture unless told otherwise, and Thai collation ignores punctuation and spaces. So IndexOf("-xmatter") matched one character late and left the hyphen on every xMatter key, and a search for "?" or "@" "matched" at position 0 of text that does not contain it. No pack matched Factory, so the default pack was null.

What the PR does

Those searches now use StringComparison.Ordinal (OrdinalIgnoreCase for the xMatter key). For a th-TH user:

  • xMatter keys and labels are right, so Collection Settings OK no longer crashes and the collection keeps its pack.
  • Page-list thumbnails show again.
  • CSS comment stripping works, so finding a book's fonts no longer throws.
  • Trimming the title-page location no longer loops forever.
  • BloomPUB preview serves the host's fonts, ePUB copyright metadata splits correctly, and PDF progress reports page numbers.
  • Record Video narration URLs, the UI-language button label, and problem-report user names come out right.

Eleven new th-TH unit tests cover these paths; all fail without the fix. The remaining culture-sensitive comparisons and a CA1310 analyzer rule are BL-16934 for 6.5.
