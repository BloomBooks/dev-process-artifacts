What this PR is about

Problem

Choosing Edit timings file... in the Talking Book tool's Adjust Timings dialog explained itself with a browser alert: titled "localhost:8089 says", English only, with the file paths crammed into the text.

What the PR does

  • The explanation now appears in a Bloom message box on top of Adjust Timings. The timings file path and the audio file name each get their own line, and runs of spaces in a path are kept. OK opens the timings file in the default editor; Esc closes the message without opening it.
  • Its three strings are now localizable (BloomLowPriority.xlf, sent to translators).
  • Bloom now finishes writing the timings file before it opens it. The alert's pause used to hide that race.
  • BloomMessageBox's buttonClicked callback, which was written but commented out, is turned on, so the dialog knows OK was clicked.
  • The old alert callback, which was passed from audioRecording.ts through workspaceRoot.ts into the dialog, is removed.
