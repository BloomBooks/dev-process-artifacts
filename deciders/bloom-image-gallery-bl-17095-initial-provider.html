What this PR is about

Purpose

The image gallery always opened on Openverse, so someone who normally takes pictures from Art of Reading or Pixabay had to switch sources every time. Bloom now wants to open the gallery on the source the user last accepted a picture from (BL-17095). The gallery needs to be told which source that is, and to report when it changes.

What the PR does

  • Adds an optional initialProviderId prop. When the gallery opens, it selects that source.
  • Adds its counterpart, an optional onPreferredProviderChange(providerId) callback, the way lang pairs with onLanguageChange. It fires when the user confirms an image from a source other than the one the gallery would now open on, and never for a file opened from disk. So the gallery decides which sources count, and the host just stores the id.
  • Waits for the named source, which may arrive late (local collections and Pixabay come after the host lists its collections). It falls back to the first source if the named one never arrives or can't be used yet (Pixabay with no key). The wait ends after 10 seconds, and closing the gallery aborts the collections request.
  • Makes the opening choice only once, so a file picked from disk is never replaced by a late source.
  • Both rules are small pure functions, chooseInitialProvider and newPreferredProviderId, with unit tests.
