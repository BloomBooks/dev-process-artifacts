What this PR is about

Purpose

The image gallery always opened on Openverse, so someone who normally takes pictures from Art of Reading or Pixabay had to switch sources every time. Bloom now wants to open the gallery on the source the user last added a picture from (BL-17095).

What the PR does

  • Adds an optional initialProviderId prop: the source to open on. If it isn't there or can't be used yet (Pixabay with no key), the gallery opens on Openverse, as before. Remembering it is the host's job; the host already gets each confirmed image's source in onConfirmSelection.
  • Adds Pixabay along with Openverse, before asking the host for local collections. So the opening source is picked at once, unless it's a local collection; then it's picked when the host's list comes back, unless the user has already picked one.
  • Compares sidebar sources by id, so React's development double mount can't leave the open source unhighlighted.
