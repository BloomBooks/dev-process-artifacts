What this PR is about

Problem

In an RO-Crate export, a file or folder whose name holds "%" gets the wrong @id. The session folder Percent %20 name becomes Sessions/Percent%20%20%20name/, which decodes to a folder that does not exist, and of the two files a b.wav and a%20b.wav one is missing from the crate (torture project finding 22).

Cause

sanitizeForIri percent-encodes spaces and a few delimiters but leaves "%" alone, so the encoding cannot be reversed.

What the PR does

  • sanitizeForIri encodes "%" as %25 first, so every id decodes back to its name and names that differ by %20 versus a space get different ids.
  • The test that pinned the old behavior is replaced; a new export test with that session folder and both files checks the crate.
