What this PR is about

Purpose

Bloom's new Collection Settings dialog (BL-16739) puts a Remove button at the right end of the "Sign Language" group's heading (and will for "Written Language 3"), which removes that language by setting its value to null. Its descriptions also need emphasis ("If you are not SURE, then do not turn this on."). Config-R had nowhere in a group heading for a control, no supported way for a client component to change a value without depending on Formik, and descriptions were plain text apart from links.

What the PR does

  • ConfigrGroup takes an optional headerAction (any React node), shown at the right end of the heading line like MUI CardHeader's action, only when the heading shows. Without it the heading is unchanged.
  • New exported hook useConfigrValue<T>(path) returns [value, setValue] for a component rendered inside the pane; a change reaches the pane's onChange just as an input edit does.
  • Descriptions render **bold** and *italic* alongside [text](link) links; they nest, and a marker must hug its text, so 2 * 3 * 4, 2*3*4, x**2 + y**2 and an unmatched ** stay as typed.
const RemoveSignLanguage = () => {
  const [lang, setLang] = useConfigrValue<object | null>('languages.signLanguage');
  return <Button disabled={!lang} onClick={() => setLang(null)}>Remove</Button>;
};
<ConfigrGroup label="Sign Language" headerAction={<RemoveSignLanguage />}>…</ConfigrGroup>
