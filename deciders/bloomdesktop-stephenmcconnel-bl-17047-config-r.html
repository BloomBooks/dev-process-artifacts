What this PR is about

Problem

In Collection Settings, pointing at an option in the Front/Back Matter list or the Bloom Library page's Bookshelf list pops up that option's description. If you then moved the pointer down the list, the description stayed open on top of the options below it.

Cause

The lists come from config-r, whose option tooltip was interactive and opened just below the option, so moving down put the pointer onto the tooltip and kept it open. config-r 1.0.0-alpha.36 fixes that (sillsdev/config-r#36).

What the PR does

  • Updates @sillsdev/config-r from 1.0.0-alpha.35 to 1.0.0-alpha.36. alpha.36 contains only that fix.
  • Keeps bloom-player at 2.22.0-alpha.2 in the lockfile; package.json asks for its newest alpha, so the update would otherwise have moved it too.
