What this PR is about

Problem

Every nightly run reports one skipped e2e test that is not a real skip: undo-physical-keys needs a person to press Ctrl+Z and Ctrl+Y on a real keyboard, so it skipped itself in every unattended run. A standing "1 skipped" hides the skips that do need work. Once the toolbox rework re-enables its seven tests, it would be the only skip left.

What the PR does

  • The test becomes undo-physical-keys.manual.ts. The BloomE2E Playwright config collects *.manual.ts files only when PLAYWRIGHT_INCLUDE_MANUAL=1, the switch and convention the component tester already uses for its manual harnesses. A normal run, and so the nightly, no longer collects it at all.
  • The test no longer skips itself, and its how-to-run comment uses the new switch.
  • The caption and the slow-steps report name a manual test without its suffix, as they already did for .spec.ts.
  • The BloomE2E README describes the convention, and the retire-CKEditor progress notes name the renamed file.
