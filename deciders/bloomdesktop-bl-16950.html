What this PR is about

Problem

The two comprehension-quiz pages in The Moon and the Cap have different headers: page 12's "Check Your Understanding" banner is at 20pt and page 13's at 10pt. You can see it in the Collection-tab preview and in any book made from the shell. Any quiz book migrated from 6.2 can drift the same way.

Cause

6.3 renamed the quiz header class from QuizHeader-style to GameHeader-style (BL-14794) and dropped the 20pt size the old class had. New pages don't notice, because the template copies a 16pt !important rule into the book. A migrated book has no such rule, so the header inherits the inline font-size that edit mode copies from the header onto its surrounding box. That loop keeps whatever size each page happened to have.

What the PR does

  • The default game-header rule in simpleComprehensionQuiz.less now sets 16pt, matching a newly added quiz page. It isn't !important, so a size set in the Format dialog still wins.
  • The same rule also matches the pre-6.3 class, so books that haven't been migrated yet (the 6.4 sample shell, downloaded books) show matching headers in the preview.
  • Accepted trade-off, noted in the code: a 6.2 book that had its own header size in the old styles gets 16pt once migrated.
