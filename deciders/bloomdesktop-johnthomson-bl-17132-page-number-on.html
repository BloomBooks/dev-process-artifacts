What this PR is about

Problem

On 13cm Square pages the page number landed inside the bottom-left corner of the text box, on top of the format gear. The card reported this for Edge to Edge with full bleed. The Default theme on 13cm Square has the same problem, with and without full bleed. A6 and the larger sizes are fine.

Cause

13cm Square's standard page margin is 5mm, where every other paper size has at least 10mm. The page number sits about 4mm above the bottom edge and is about 6mm tall, so the margin has no room for it below the text.

What the PR does

  • When page numbers are showing, numbered 13cm Square pages keep 5mm more space below the text, which is the room A6 has. The Default theme adds it as page padding. Edge to Edge with full bleed raises its text box's bottom inset instead, so pictures still reach the bottom edge. Edge to Edge without full bleed is unchanged.
  • The Test branding's butterfly stamp moves from ::after to ::before. It had been replacing the page number on every page of e2e books made with the Enterprise test subscription.
