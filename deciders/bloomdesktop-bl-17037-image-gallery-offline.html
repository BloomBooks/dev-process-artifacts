What this PR is about

Problem

With the computer offline, searching Openverse or Pixabay in the Image Chooser did nothing visible: no error, no "No matches found", just an empty results area. The fix is in the bloom-image-gallery package (bloom-image-gallery#23, merged), and Bloom doesn't get it until it picks up that version.

What the PR does

  • Pins the gallery to 5c7e7f4 (version 0.0.5) in package.json and pnpm-lock.yaml; only the gallery's entries change. In the Image Chooser:
    • a search that can't reach the website says "Could not reach Openverse. Check that this computer is connected to the internet.";
    • a warning shows while the computer reports being offline;
    • any other failed search shows an error instead of an empty area.
  • Adds the two new strings to BloomLowPriority.xlf (your choice of file): ImageLibrary.CannotReachSource and ImageLibrary.ComputerSeemsOffline. Both are translate="no", and each has a note for translators.
