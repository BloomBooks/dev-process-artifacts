What this PR is about

Problem

pnpm audit reported 162 alerts, 9 of them critical. Almost all come from dev tooling: Storybook, Vitest, semantic-release and the build plugins. Three lodash advisories, however, are in code that ships. lodash is a runtime dependency, and react-color, which is bundled into dist, carries lodash-es.

What the PR does

  • Clears the critical alerts by upgrading the tools. Storybook 8.2.8 → 8.6.19 removes the express and tar chains. Vitest 2.1.9 → 4.1.12 removes tinypool; it needs Vite 5.4.11 → 6.4.4 and @vitejs/plugin-react 4.7.0. Vite 6's esbuild is added to the install-script allowlist.
  • Fixes the alerts in shipped code. lodash 4.17.21 → 4.18.1, and react-color's lodash-es is refreshed.
  • Removes unused dev dependencies: plugin-react-refresh, babel-loader, and semantic-release's commit-analyzer and changelog plugins.
  • Bumps tooling within its current major version, and refreshes the transitive packages the audit flagged. Prettier 3.9 reformats two files.
  • Adds an AGENTS.md that says which tracker a branch uses.

The audit now shows 0 critical · 10 high · 7 moderate · 1 low, none of it in shipped code. The rest is in ESLint 8 and Storybook 8.

Worth knowing

  • Merging to master starts semantic-release on the alpha channel. The first commit's message isn't in conventional-commit form, so reword it to chore(deps): when pr-ready-for-human squashes the branch. Removing the separately installed commit-analyzer is only exercised on master.
  • The published bundles are now built by Vite 6 and include lodash 4.18. Nobody has compared their contents or tried them in Bloom. Before the next release, the cheapest real check is to try the build in Bloom. The type declarations are byte-identical.
  • Nobody has opened the Storybook dev server and looked at the stories. Only build-storybook was run.
  • Something odd that predates this PR: with "type": "module", Node treats configr.cjs.js as ESM, so a plain Node require() of the package would fail. Bundlers aren't affected. This PR leaves it unchanged.
