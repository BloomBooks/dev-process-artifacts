What this PR is about

Problem

The page theme "Zero Margin Ebook" takes pictures to the page edge, but only on ebook and device page sizes. Full-bleed print books need the same thing at any paper size, and the name no longer describes the theme once it is used for print. This is part 1 of 3 of the BL-15958 work; the full-bleed page sizes (PR 8263) and the edit-mode crop marks (PR 8264) are separate.

What the PR does

  • Renames the theme to Edge to Edge. A book that stores the old name is read and saved as the new one (AppearanceSettings.cs:186), and the eBook and Playground templates and the EFL ebook migration use the new name.
  • Applies the theme to every page size. Numbered content pages have no margin; front and back matter keep 3mm.
  • With full bleed on, text boxes stay 3mm inside the trimmed edge, and page numbers placed left or right line up with the text and shift with the trim offset.
  • Keeps master's format-button placement for the theme's ebook pages (BL-14901): it moves clear of a bottom-left page number on landscape pages and stays put on portrait pages, where the number is centered.
  • The full-bleed help text in Book Settings now names the theme. The theme label and that help text get new translatable string ids; the old entries are kept and marked obsolete as of 6.6.

1. Should this PR target master or Version6.5?

The repo's AGENTS.md says that, for now, new work should branch off and merge into Version6.5. This PR and its two siblings (8263, 8264) all target master, the card's summary has no [6.5] prefix, and the PR was opened four days after that note was added. Devin flagged the mismatch. Retargeting means rebasing three PRs onto Version6.5 and re-running their reviews.

2. Existing paper-size books that use this theme will lose their margins

Before this PR the theme only changed ebook and device pages; a book using it at a paper size such as A5 kept the default margins. The eBook and Playground templates start with this theme, so a book made from them and switched to A5 has it. Once this ships, that book's content pages go to no margin and its front and back matter to 3mm, without the user doing anything. The card's own first item is "allow all layouts to participate", so this may be exactly what you want.

3. The PR description is out of date

The description was written by an earlier agent run, without the markers preflight uses to refresh it, so this run left it alone. It now says the PR updates the theme label in all localization files, which this run reverted, and it lacks the reviewer sections (Risk Evaluation, Ecosystem Impact, E2E Coverage, Notion Test Suite).
