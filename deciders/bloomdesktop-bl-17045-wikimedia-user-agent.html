What this PR is about

Problem

When an Openverse search in the Image Chooser finds a picture hosted on Wikimedia Commons, clicking Use this image fails with "403 (Forbidden)". Those pictures also show no preview in the results grid.

Cause

  • The 403: the Image Chooser downloads with an HttpClient that sends no User-Agent, and upload.wikimedia.org refuses every such request. With any User-Agent, the same request gets 200.
  • No preview: Openverse's thumbnail service fails for Wikimedia pictures. That half is fixed in bloom-image-gallery #24.

What the PR does

  • The Image Chooser's download client now identifies itself as Bloom/<version> (https://bloomlibrary.org), the form Wikimedia's policy asks for (ImageGalleryApi.cs:37).
  • It pins bloom-image-gallery 0.0.6 at 027c9ed, the single commit of gallery #24, in which Openverse results hosted on Wikimedia get their previews straight from Wikimedia.
