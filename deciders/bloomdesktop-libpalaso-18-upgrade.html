What this PR is about

Problem

Bloom was on libpalaso 18.0.0-beta0046, a prerelease. libpalaso 18.0.0 shipped on 2026-10-12. We were also skewed on L10NSharp: Bloom referenced L10NSharp 11.0.1, but L10NSharp.Windows.Forms, whose LocalizationManagerWinforms Bloom calls directly, arrived only through libpalaso, at 10.0.0-beta0004.

What the PR does

  • Moves every project to libpalaso 18.0.0 and SIL.libpalaso.l10ns 18.0.0.
  • Moves L10NSharp to 12.0.0-beta0006, the newest on NuGet. L10NSharp.Windows.Forms becomes a direct reference at the same version, which ends the skew.
  • Raises two direct pins that 18.0.0 now needs: Markdig.Signed 1.4.0, and Microsoft.Extensions.DependencyModel 10.0.9 for icu.net 4. That also makes Bloom load System.Text.Json 10.0.9 instead of the shared framework's 8.x.
  • Drops a System.Resources.Extensions pin that libpalaso now sets itself.
  • Records the upgrade in docs/winforms-dependencies/PLAN.md. The WinForms surface is unchanged.

beta0046 is only 4 commits behind v18.0.0, so the 18.0.0 changelog's breaking items (ordinal comparisons, GlobalMutex, ImageCropper and so on) already ship on master. The per-item review is in the PR description.
