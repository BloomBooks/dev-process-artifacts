What this PR is about

Problem

On a derivative book's credits page, the user can unlock the "adapted from the original" sentence and reword it. When that book is exported to a spreadsheet and imported into a new book, their wording is lost. The credits page goes back to Bloom's generated sentence, without the original title and with the stored original copyright.

Cause

The spreadsheet's * column holds book-wide data-div values. Export wrote them as raw XML (& as &amp;, tags kept), but import XML-escapes everything it reads from that column. So the user's wording came back as literal tag text, and any & in the original title, copyright and similar fields doubled on every round trip.

What the PR does

  • Export writes * column values as plain text, so import's escaping restores exactly the original value.
  • The user's wording is real formatted text (paragraphs, italic title), so its * cell gets the rich-text treatment ISBN already had. Its formatting survives, and it can be edited in Excel like book text.
  • A new round-trip test writes and reads a real .xlsx and checks the original title, copyright, license and the user's wording all come back unchanged.
