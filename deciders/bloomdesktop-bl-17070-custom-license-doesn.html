What this PR is about

Problem

On a derivative book's credits page, the user can unlock the "adapted from the original" sentence and reword it. When that book is exported to a spreadsheet and imported into a new book, their wording is lost: the credits page shows Bloom's generated sentence, with "click to edit original title" and the stored original copyright year.

Cause

  • The import ran on stale book data. The importer writes straight into the book's data div, then brings the book up to date. But a book reads its values only when it loads, so that update used the blank book's values. It saw no derivative and no user wording, generated the sentence itself, and removed the original title.
  • The * column was escaped twice. Export wrote book-wide values as raw XML and import escaped them again, so the user's wording came back as literal tag text and any & doubled on every round trip.

What the PR does

  • After writing the data div, the importer has the book re-read its data before bringing it up to date.
  • Export writes * column values as plain text, so import's escaping restores exactly the original value.
  • The user's wording gets the rich-text treatment ISBN already had, so its italics survive and it can be edited in Excel.
