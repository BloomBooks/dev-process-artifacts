What this PR is about

Problem

A spreadsheet has one row per text block and one cell per language, and a cell holds only text with bold, italic and underline. So exporting a book whose text blocks hold pictures, and importing it back, lost the pictures.

What the PR does

  • Export writes an [inline image] row for each picture after its block's row. The file goes in the usual image column. Position, width, offset (with the block size it was measured in) and transparency go as JSON in a new hidden [details] column.
  • Import from a sheet with that column treats the rows as the truth. It rebuilds the pictures in every box of the block, including languages the sheet lacks and the hidden lang="z" copy. It fills in the image's copyright and license. Deleting a row deletes the picture, and an unusable hand-edited value gets a warning naming its row.
  • A sheet without the column (from an older Bloom, or a block that is an image description) keeps the pictures the book already has.
