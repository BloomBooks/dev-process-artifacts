What this PR is about

Problem

The new React Collection Settings dialog (from BL-16902) had seven placeholder pages. The Experimental page needs its real setting so it can replace the "Experimental Features" section of the old dialog's Advanced tab.

What the PR does

  • The Experimental page offers exactly what master's old dialog offers there: a Team Collections checkbox with the subscription badge. The old "Show Experimental Book Sources" toggle is never shown on master, so it is not here either.
  • A disabled checkbox row in either Config-R settings dialog is now faded once instead of twice (the shared ConfigrDialogMiddle), so it is readable; this includes Book Settings.
  • The page lives in its own file, collection/settingsPages/ExperimentalPage.tsx, as a hook returning its ConfigrPage; each tab card moves its page out of the dialog the same way. Each row is a general ExperimentalFeatureSetting.
  • The checkbox is disabled when the subscription tier lacks Team Collections, or when the user is inside a Team Collection with the feature on, as in the old dialog. It also stays disabled until Bloom has answered the subscription check, which the old dialog did not do; the dialog asks as soon as it opens, so the box doesn't flash greyed out. GET collection/settings now also says whether the open collection is a Team Collection.
  • Saving reuses the shell: changing the box turns OK into Restart, which saves the choice and reopens the collection.
  • A new e2e journey test drives Settings → Experimental → tick → Restart and checks the saved setting, with new helpers for the React dialog. Unit tests cover the three disabled states.
