What this PR is about

Purpose

After #8598, a table cell set to L1 was stored as V, which shows whichever language the toolbar ticks first. So changing the toolbar changed the book's tables, and when the toolbar put another language first, the collection's first language could not be chosen for a cell at all. This PR adds a role, CL1, that names the collection's first language whatever the toolbar shows, and makes the table's menu use it.

What the PR does

  • CL1 works in any text box, not only tables: Bloom shows its box, counts it when publishing, makes the box when the toolbar leaves that language out, and runs it right to left when it should.
  • CL2/CL3 are other names for N1/N2, translated in the one place every reader of a group's roles goes through. Nothing writes them yet; they anticipate retiring N1/N2 after 6.6.
  • Bloom before 6.6 refuses a book that uses these roles (a new feature requirement), since it would show such a box in no language.
  • The table menu writes CL1/N1/N2, and a new cell starts as CL1 with a box in the collection's first language.
  • No special case for old cells: the few test-team cells with no setting or V show what Bloom shows for them, with nothing ticked in the menu.
  • Bloom Player gets the matching change in bloom-player #450.
