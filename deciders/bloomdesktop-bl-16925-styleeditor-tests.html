What this PR is about

Problem

After #8408, the nightly still skipped 2 Vitest tests, both in the StyleEditor spec: "…MakeBigger replaces the existing rule" and "…ChangeSizeAbsolute replaces the existing rule". They were skipped in the Vitest move because they read computed styles, which jsdom doesn't really support. The same reason had kept the overflow tests off.

What the PR does

  • Renames StyleEditorSpec.ts to StyleEditor.browser.spec.ts, so the whole file runs in the browser project (headless Edge) from #8408, and un-skips the two tests. All 23 pass.
  • Removes the two obsolete "skipped because jsdom" comments and adds one line at the top saying why the file runs in the browser.

pnpm test now runs 969 tests with none skipped. The last nightly had 967 passed and 2 skipped.
