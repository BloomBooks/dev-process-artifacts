What this PR is about

This PR changes only a test helper.

Problem

Since it was added on 2026-11-27, TC-401 (publish-save-outside-collection.spec.ts) has failed on the GitHub runner every time. It picks a PDF file name inside the collection folder in Save As and then waits in vain for Bloom's refusal. TC-660's Bloom Pack test fails there the same way, because it uses the same helper.

Cause

The fault is in the test, not in Bloom. Logging on the runner showed that when Save was pressed, the dialog's "File name:" box held the path the test had set. Even so, SaveFileDialog handed Bloom the dialog's own suggested name in Documents. The dialog keeps a name of its own, which follows typing but, on the runner, not text set through UI Automation's SetValue.

What the PR does

  • answerSaveAsDialog waits for the dialog's suggested name, empties the box and posts the path to it a character at a time (WM_CHAR). That needs neither the foreground nor the focus.
  • It waits until the box holds the path. If the box settles on anything else, it types the path again. A refused character post fails the call at once.
