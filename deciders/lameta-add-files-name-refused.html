What this PR is about

Problem

When a user chose several files in Add Files and one of them was a .session, .person or .meta file (or a folder), lameta added none of them and showed one warning that did not say which file it objected to.

What the PR does

  • Add Files still refuses the whole selection, as John chose, but the warning lists each refused file with its reason.
  • The check that finds refused files looks at every path, not only up to the first that fails, and has a unit test.
  • Toast details keep their line breaks. A second refusal while the first warning is showing gets its own warning, and lameta.log records the names.
