FYI: text hidden by CSS and the current page's counts

Greptile pointed out that the current page's statistics now come from Bloom's reader text walker instead of the browser's innerText. So text inside a text box that is hidden only by CSS visibility: hidden or the HTML hidden attribute would now be counted. Bloom does not put such content in text boxes. The hidden markup it does add (its own UI, editor bookmarks, Talking Book markers, inline display:none) is already skipped. Also, the page marking and every other page's book totals never honored CSS, so the old behavior made the current page the odd one out. For those reasons preflight replied to the thread and resolved it, and recommends leaving it as is.
