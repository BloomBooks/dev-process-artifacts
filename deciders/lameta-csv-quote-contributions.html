What this PR is about

Problem

In File > Export Project... > Zip of CSVs, a session whose contributor name holds a comma (Smith, John) gets one more column in sessions.csv than the header. A quote or a line break in a name makes the file unparseable. Found by the torture project (finding 21).

What the PR does

The contributions cell now goes through csvEncode, like every other cell in the row. A unit test exports contributors named Smith, John and one with a quote and a line break, parses the result with a standard CSV parser, and checks the column count and that both names survive.
