What this PR is about

Problem

In Book and Page Settings, a dropdown choice long enough to set the dropdown's width ran under the down arrow, e.g. Text Padding's "Par défaut (défini par Thème)" in French. BL-16958 worked around it in Bloom; the real fix is now in config-r (sillsdev/config-r#28, released as 1.0.0-alpha.29).

What the PR does

  • Bumps @sillsdev/config-r from alpha.27 to alpha.29. The lockfile change is only that package's version and integrity, and the library itself differs only by the padding fix.
  • Removes the BL-16958 workaround, which set the same 32px right padding, from ConfigrDialogMiddle.tsx.
  • Exempts @sillsdev/config-r from pnpm's 7-day release-age gate, as we already do for bloom-player, comicaljs and @ethnolib. Without it, alpha.29 couldn't be installed until 10-13.
