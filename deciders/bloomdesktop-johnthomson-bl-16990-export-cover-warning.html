What this PR is about

Problem

Exporting a book to a spreadsheet warned "did not find the image <guid>.jpg. It will be missing from the export folder." when the book's custom front cover had a picture made into the background. The picture was in fact exported; the warning was false.

Cause

Export first crops every picture into the export's images folder. When a cropped picture needs a new name (the same picture is also used uncropped, or one crop is used on several pages), the renamed file exists only in the export folder. CopyImageFileToSpreadsheetFolder looked in the book folder and warned before checking the export folder.

What the PR does

  • The exporter now returns quietly when the picture is already in the export's images folder, and only then warns about a missing source. A picture used on several pages is copied once.
  • Regression tests: no warning for renamed crops (cover and shared page picture), and a truly missing picture still warns.
