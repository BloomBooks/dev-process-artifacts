What this PR is about

Problem

The Decodable Reader tool's Set Up Stages dialog was a legacy jQuery page in a window of its own: styled unlike the rest of Bloom, and hard to change.

What the PR does

  • Rebuilds the dialog in React inside Bloom's standard dialog, with the same three tabs (Letters, Sample Words, Decodable Stages) and the same settings file.
  • On Decodable Stages you click letters into a stage, type sight words, and add, remove and drag stages to reorder them, with a live preview of the words that match.
  • Sample Words lists every file in the Sample Texts folder and says why a file won't be read, instead of hiding it. Words typed one per line are saved as separate words.
  • Fixes found along the way: Set Up Stages did nothing if pressed before the settings had loaded; the Sample Words tab failed after the toolbox reloaded; a letter combination removed from the alphabet kept affecting word analysis. It also removes a help link that pointed at the wrong page, and Help now shows even when a non-administrator can't edit.
  • The Leveled Reader's Set Up Levels dialog is deliberately untouched and still uses the legacy code, which goes when that dialog is converted.
  • Adds unit tests and an end-to-end journey test.
