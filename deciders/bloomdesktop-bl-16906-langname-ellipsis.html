What this PR is about

Problem

On the Collection tab, the "N language books on BloomLibrary.org" label under the progress bar cuts any language name longer than 12 characters down to 11 plus "...", even when there is plenty of room. "Lala Bisa (Chilala) Language" shows as "Lala Bisa (...".

What the PR does

  • The label now gets the full language name.
  • It is shortened with an ellipsis only when it really doesn't fit on the row.
  • When it is shortened, the existing "View on BloomLibrary.org" hover tooltip also shows the full label. That tooltip is reused rather than adding a native title, so a hover still produces only one popup.
  • The label and progress bar stay 312px wide as before, but grow, up to the width of the pane, when a long name needs the room. In a pane narrower than 312px they now fit inside it instead of running past its edge.
  • There is a 20px gap before the "Goal: N" text, and "Goal: N" never shrinks, so it stays fully visible.
