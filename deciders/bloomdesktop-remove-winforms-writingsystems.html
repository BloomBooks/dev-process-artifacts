What this PR is about

Problem

Bloom references the WinForms-only package SIL.Windows.Forms.WritingSystems for one thing: a static LanguageLookupModel in Collection/WritingSystem.cs. It is one of the WinForms dependencies the WinForms dependency plan sets out to remove.

What the PR does

  • WritingSystem now holds a LanguageLookup from the netstandard SIL.WritingSystems package, which Bloom already references. It is built exactly as the model built it, so language lookups give the same answers. The retry for an abandoned SLDR mutex (BL-16802) still wraps the call that takes the mutex.
  • The package reference is gone, and the plan no longer lists it. Keyboarding and WindowsAPICodePack are the one-call packages left.
