What this PR is about

Problem

On Publish > Web, a subscriber sometimes sees a red "Bloom could not reach the server to get the list of bookshelves" banner, and the Upload button is greyed out. She can't upload, though the upload itself would work. It depends on timing: click Upload quickly and it works; wait a few seconds and the button is already disabled.

Cause

The bookshelf list comes from Contentful, which refuses requests from some regions (Venezuela, for the BL-16987 user). Any failure of that lookup disabled Upload, but only after Contentful's client finished its retries, which is why timing mattered.

What the PR does

  • A failed bookshelf lookup is now a yellow warning, and Upload stays enabled.
  • Bloom then can't check that the collection's bookshelf belongs to the subscription, so the book is tagged with it unchecked. C# still requires a matching subscription with a tier that allows bookshelves.
  • The one gap is that a user with a paid subscription could hand-edit their collection to name another organization's shelf and block Contentful. It is documented in the code as acceptable (LibraryPublishSteps.tsx:434).
