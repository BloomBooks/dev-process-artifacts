What this PR is about

Developer tooling only: .claude/skills/branding-report/. Nothing ships in Bloom. No card.

(1/2) Flavor brandings could not be surveyed

Problem. Only branding folder names were listed, so flavor variants such as Pioneer-Bible[vanilla] and Global-Partners[vanilla] could not be picked in the control panel or captured with survey.mjs --brandings all.

Fix. A shared listBrandings() lists each folder plus Folder[flavor] for every branding[flavor].json. Both control.mjs and survey.mjs use it.

(2/2) The panel ignored selections made through its API

Problem. When an agent POSTed a selection to /api/selection, the server captured it, but the open panel kept showing its old picks.

Cause. The page adopted the server's selection only once, at load, and never adopted brandings.

Fix. The page adopts the server's whole selection whenever the server's version advances. It skips this while its own POSTs are in flight. If a POST fails, it re-adopts and redraws the server's selection.
