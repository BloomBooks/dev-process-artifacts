What this PR is about

Problem

After a clean build of master, Bloom never shows its workspace. Every stylesheet request fails with Could not find the directory output\browser\collection, so every e2e test fails at launch, and a clean Release build (the nightly's, an installer's) should fail the same way.

Cause

Bloom's list of folders that it searches for files to serve still named output/browser/collection, and that search throws when a folder is missing. The front-end build made that folder only to hold enterpriseSettings.less. PR #8516 (BL-17042) deleted that file, which left only TypeScript, and TypeScript is bundled elsewhere. A checkout built before that merge still has the old folder, so the problem shows only after the output is cleaned.

What the PR does

Removes output/browser/collection from the search list (ProjectContext.GetFactoryFileLocations). Nothing is served from it any more.
