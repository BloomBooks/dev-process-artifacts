What this PR is about

Problem

Testers have v3.0.21-beta, and master has many PRs since. Nothing showed what those PRs changed in the files lameta exports (IMDI, OPEX, RO-Crate, CSV, PARADISEC, and the metadata lameta saves). Comparing two versions by hand fails, because every export differs in its date, lameta's version and random guids, and on master by a lameta-source comment before each IMDI element.

What the PR does

  • compare-exports.ts run runs the export harness in any lameta worktree, on a copy of the project, because loading a project writes into it. A version too old to have the harness gets a copy of it, and one from before Vite+ runs under the Node version that its package.json names.
  • It writes the output without what changes from run to run: export dates, lameta's version, file times, random guids and the paths of the run.
  • compare-exports.ts diff lists each changed line, or each changed CSV cell, once, with the files that it is in. --ignore-source-comments handles comparing with a version that predates those comments.
  • The harness also writes the three generic CSVs and each session's RO-Crate as files.
  • Master's normalized output for the portable torture project is the golden set. It is in #114, stacked on this PR, because Devin cannot review a diff of about 590,000 generated lines. Two runs give identical files.
