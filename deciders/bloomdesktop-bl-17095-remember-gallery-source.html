What this PR is about

Purpose

The image gallery always opened on Openverse, so someone who gets their pictures from Art of Reading or Pixabay had to switch sources every time. Now it opens on the source the user last accepted a picture from, as long as that source is still there and usable. Otherwise it falls back to Openverse, as before.

What the PR does

  • Adds a user setting, ImageGallerySource. When the user accepts a picture, the dialog saves the picture's source id in it. It skips files opened from disk, and skips the save when the source hasn't changed.
  • When the gallery opens, the dialog reads that setting along with the provider keys it already loads, and passes it to the gallery's new initialProviderId prop.
  • Moves the bloom-image-gallery pin to the branch of bloom-image-gallery#26, which merges first; the pin then moves to its merge commit. Nothing else comes in with the pin.
