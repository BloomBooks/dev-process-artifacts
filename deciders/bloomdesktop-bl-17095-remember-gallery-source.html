What this PR is about

Purpose

The image gallery always opened on Openverse, so someone who gets their pictures from Art of Reading or Pixabay had to switch sources every time. Now it opens on the source the user last accepted a picture from, as long as that source is still there and usable. Otherwise it falls back to Openverse, as before.

What the PR does

  • Adds a user setting, ImageGallerySource. The gallery decides which accepted pictures change the source to open on (not files from disk, not the source it already prefers) and reports the new source through its onPreferredProviderChange callback; Bloom stores what it is told.
  • When the gallery opens, the dialog reads that setting along with the provider keys it already loads, and passes it to the gallery's new initialProviderId prop, the counterpart of that callback.
  • Moves the bloom-image-gallery pin to the branch of bloom-image-gallery#26 (now 5625bb7), which merges first; the pin then moves to its merge commit. Nothing else comes in with the pin.
