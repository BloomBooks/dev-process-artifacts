What this PR is about

Purpose

The image gallery always opened on Openverse, so someone who gets their pictures from Art of Reading or Pixabay had to switch sources every time. Now it opens on the source the user last added a picture from, as long as that source is still there and usable. Otherwise it falls back to Openverse, as before.

What the PR does

  • Adds a user setting, ImageGallerySource. After a picture is in the book, the dialog saves the source it came from (not for a file from disk); a download that fails doesn't change it.
  • When the gallery opens, the dialog reads that setting along with the provider keys it already loads, and passes it to the gallery's new initialProviderId prop.
  • Moves the bloom-image-gallery pin to the branch of bloom-image-gallery#26 (now 7cbccb6), which merges first; the pin then moves to its merge commit. Nothing else comes in with the pin.
