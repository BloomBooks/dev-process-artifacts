What this PR is about

Problem

In the Open / Create Collections dialog, the button in the title bar that shows Bloom's current user-interface language displayed the language name in all capitals ("ENGLISH"). The same menu everywhere else in Bloom shows normal casing, and the card asks for the dialog to match.

What the PR does

The dialog's own title-bar styling contained a rule that forced the language button's label to uppercase. That rule is removed, so the button now shows the language name exactly as the shared UI language menu renders it ("English"). The button's 14px size and normal weight in this dialog are kept. One file changes: CollectionChooserDialog.tsx, lines 54 to 67.
