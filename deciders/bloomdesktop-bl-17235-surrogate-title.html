What this PR is about

Problem

The surrogate-pair title test (Test Case ID 667) failed in the 2026-11-28 nightly. Locally it fails about one run in ten, at its first check that Bloom reported no problem while the book took the title's name. The problem it reports is "web socket is not available when trying to send".

Cause

When the test leaves the cover, Bloom renames the book after its title and sends an event to every open web socket. The socket of the page the test has just left is sometimes closing at that moment. Bloom reports that as a problem only on the Developer channel, which every e2e run is on. On any other channel it only writes it to the log. The title plays no part in it.

What the PR does

The test's two checks for problems leave out that one message, matched exactly, and still fail on any other problem. An Opus reviewer agreed that the test was failing on something it does not mean to check.
