What this PR is about

Problem

When Windows stops Bloom from writing a PNG in a book folder, the "Could not update PNG image" notice has a Details button. In 6.5 those details list a dozen or more facts about the file, the folder, the sync provider, Controlled Folder Access and the antivirus. In the Details dialog they all run together in one unbroken block, which is hard to read (tester feedback on BL-16915).

Cause

The Details button joins the lines with a newline, but the dialog renders its message as HTML, where newlines collapse into spaces.

What the PR does

The Details button in NonFatalProblem.ShowToast now joins the lines with <br>, so every fact is on its own line. The help line, which already carries line breaks on each side (#8422), becomes its own paragraph.

  • Only the text going into the dialog changes. The log and Sentry still get the original newlines.
  • Only the PNG-write notice uses this button (plus a dev-only toast test). Its text contains no literal < or &, and it was already treated as HTML there.
