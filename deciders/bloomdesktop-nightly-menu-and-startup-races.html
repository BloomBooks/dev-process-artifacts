What this PR is about

Problem

Two nightly failures, each a race between a test and Bloom. On 11-01 the e2e test rotate-and-flip-images (Change Image) left the Flip submenu open, and the menu helper gave up after 30 s. On 11-02 the visual regression suite's first case, right after launch, asked Bloom for a BloomPUB preview and Bloom threw because no book was selected.

Cause

  • The submenu opened because its row got keyboard focus. Bloom's submenus (mui-nested-menu-item) open on mouse-enter or focus but close only on mouse-leave or ArrowLeft, so the helper's "move the pointer off" never closes a focus-opened one.
  • e2e/isCollectionReady turns true as soon as the collection's books can be listed. Bloom's own startup selection runs after that: it clears the selection and then reloads the last-selected book. The test's call landed in that gap.

What the PR does

  • The e2e helper closeCanvasElementMenu closes a submenu with Escape on the submenu, after giving the menu the focus so the submenu cannot hand it back to its own row and reopen.
  • Bloom reaches a new startup milestone, startupBookSelected, when WorkspaceView.SelectBookAtStartup finishes (in a finally, so always). e2e/isCollectionReady stays false until then. Nothing users run waits on it.
  • Records both failures and their causes in docs/nightly-failures/README.md.

Worth knowing

  • Neither race can be forced locally: a focus-opened submenu needs Bloom's window to have focus, which an agent's --dont-disturb run never has. The nightly is where both fixes get proven.
  • Why focus landed on the Flip row on 11-01 is still unknown; the fix makes it not matter.

Test of the change

The PR adds no test of its own. Both changes fix races that only show under timing or window focus a local run cannot set up, and the code they change is already run by every nightly: every e2e spec and the visual regression suite wait on isCollectionReady at launch, and four specs close menus through the changed helper. A test that forced either race would need a hook in Bloom to make startup slow or to give a menu row focus.
