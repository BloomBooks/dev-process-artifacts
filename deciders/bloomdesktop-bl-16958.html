What this PR is about

Problem

In Book and Page Settings, a dropdown whose chosen value is long runs its text under the down arrow. With the UI in French, both Text Padding (“Par défaut (défini par Thème)”) and Page Gutter (“Par défaut (selon le Thème)”) hit this.

Cause

config-r’s select control forces a 3px padding on itself with !important. That removes the 32px that MUI keeps on the right for the arrow. Short values hide the problem because the select’s 180px minimum width leaves room anyway. config-r 1.0.0-alpha.27, used on Version6.5 and master, has the same code, so the fix is wanted there too when it merges forward.

What the PR does

The settings dialog puts MUI’s 32px right padding back on its selects, using a selector specific enough to beat config-r’s rule (BookAndPageSettingsDialog.tsx:477). Short values look the same as before. Long values now widen the select instead of running under the arrow. I checked this in live Bloom, before and after, with the French labels inserted into the dialog.
