What this PR is about

Purpose

The Front/Back Matter list in Collection Settings shows a description under each pack. Those descriptions lived in description-<lang>.txt files in each pack's folder, which Crowdin never sees, so nobody has translated them since 2017 and any change to the English stranded the old translations. This PR makes them ordinary localizable strings, so they reach translators like the rest of the UI.

What the PR does

  • Moves every shipped pack's description into the English XLF, with an id next to the pack's name id: standard packs in Bloom.xlf, project-specific ones in BloomLowPriority.xlf. They are translatable now.
  • Tidies the English as it moves: Traditional now reads “Like a printed book, this puts the credits on the back side of the title page.”
  • XMatterInfo.GetDescription looks descriptions up through L10nSharp; a pack a user installed, with no XLF entry, still uses its own files.
  • Deletes the 51 description files of the packs Bloom loads.
  • Saves the old Paper Saver, Super Paper Saver and Traditional translations, with a script to upload them to Crowdin as unapproved suggestions after merge.
