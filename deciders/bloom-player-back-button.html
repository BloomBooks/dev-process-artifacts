What this PR is about

Problem

A host app that embeds bloom-player in an iframe and passes showBackButton=true gets an ellipsis ("More") on that button instead of a back arrow. The App Builders PWA (appbuilder-pwa #1137) hits this. Its button really does go back, so it currently uses a MutationObserver to rewrite our SVG path and aria-label inside the iframe.

Cause

When the player has no in-book history, it picks the icon from where it is running: an arrow if it is the top window (Bloom Reader), an ellipsis if it is embedded. The ellipsis is for bloomlibrary.org, where the button opens the book's detail page. A host had no way to say which it meant.

What the PR does

  • New URL param backButtonIcon=arrow|ellipsis overrides that automatic choice (bloom-player-controls.tsx:942). If it is missing or has any other value, behavior is unchanged. Once the reader has followed a link within the book, the button is still always an arrow.
  • README documents the param (README.md:70) and corrects the showBackButton note, which had the top-level and embedded cases backwards.

Decisions

What should we do about the App Builders PWA's page-scaling workaround?

The PWA's BloomPlayerElement.svelte injects its own stylesheet into the player's iframe. It recomputes the page scale from a table of page sizes in millimetres, because in their setup the page's CSS width resolves to none, so the player measures the wrong size once and keeps it. You don't want a page-size table in bloom-player. Without that table, the player can only size a page from the book's own CSS, so the fix has to make that CSS apply.

I could not reproduce the problem with a current Bloom book in an iframe, and bloomlibrary.org embeds the player the same way. Their file renaming only normalizes Unicode, and our scoped-style polyfill only rewrites selectors, so neither should drop the --page-width variables. The likeliest causes are on their side: a book stylesheet that fails to load (bloom-player skips failed stylesheets silently), an App Builders step that rewrites the book's CSS and drops custom properties, or an old bloom-player copy.
