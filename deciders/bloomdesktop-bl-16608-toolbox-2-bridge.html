What this PR is about

Problem

The React toolbox (ToolboxRoot) publishes an adapter on window, and toolbox.ts checks for it at every call site. When it is missing, the code falls back to driving the old jQuery accordion. ToolboxRoot always mounts before ToolBox.initialize(), so those fallbacks can never run. They are dead code that keeps toolbox.ts tied to the accordion. This is the second of four PRs retiring the legacy toolbox (BL-16608), and like the first (#8402) it should change nothing a user sees.

What the PR does

  • Removes the unreachable accordion fallbacks from toolbox.ts.
  • Replaces the window.toolboxReactAdapter global with a small module with get/set accessors, and drops two adapter methods nothing needs. The BL-16602 unit tests read the adapter through the module and check which section is open in the rendered page. The Playwright component harness gets a test-only accessor.
  • Stops loading jquery.qtip.css in the toolbox frame, where nothing is a qtip. The page frame loads its own copy.
  • Updates the canvas test docs to the selector the canvas helpers already use.
