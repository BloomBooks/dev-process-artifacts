What this PR is about

Problem

Bloom's Edit tab shows one page at a time. People laying out a children's book want to see the page they are editing beside its facing page, and the rest of the book around it, the way it will be read (community request).

What the PR does

  • A page view chooser in the Edit tab's top bar switches between one page at a time and all pages, remembered across pages and sessions. Choosing all pages zooms out if the spread would not fit.
  • All pages lays the book out the way it is read: the front cover alone, then facing pages in pairs. Right-to-left books are mirrored, calendars stack each upper page above its lower page, and books sized for a screen show single pages. The other pages are read-only, drawn only near the screen, and pick up Format dialog changes at once. None of it is saved.
  • Clicking another page opens it in place and replays the click (caret in the text, or the picture selected), through the page list's queue from PR 8209. Nothing else on the new page takes the focus, a click opens only that page, and zooming keeps the page in place.
  • Page changes hold steady in both views: the new page loads under the old one and replaces it once laid out. This needs PR 8209.
  • Remove Page scrolls the page being edited into view with a red X across it while the user confirms.
  • The controls above the page (Change Layout, game tabs) sit in a bar fixed at the top of the page frame.
  • Two commits belong elsewhere: 401a192c41 is a fix for PR 8209, and b8039ae906 is BL-16933's Image Description fix.

Decisions

Check the controls bar on a game page

With this branch, the controls shown above a page (the game tabs Start, Correct, Wrong and Play on a game page, and the Change Layout switch) move into a bar fixed across the top of the page frame, so they stay put while the pages scroll. Styles written for those controls back when they sat just above the page may still apply to them in the bar (origamiEditing.less, lines 160 to 169). On a game page, especially in a narrow window, the tabs could then be misaligned or cut off.

Nobody has looked at a game page with this branch, and no test covers it. Devin raised it; the thread is open.
