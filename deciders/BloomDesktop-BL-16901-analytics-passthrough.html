What this PR is about

Problem

Bloom kept a list of the analytics event names the AI Image Editor was allowed to send, and silently dropped anything else. The AI Image Editor has since added events, so those never reached Segment, and it looked as if nobody was using those features.

What the PR does

Commit 1 — forward all events.

  • Remove the list. Bloom now forwards every event the AI Image Editor sends, with its properties. The only change is the name prefix: AI Editor Generate becomes AI Image Editor Generate.
  • Add aiEditorSessionId to every forwarded event and to Bloom's own closing event, so all the events from one session can be grouped.
  • Remove generatedThisSession. It only worked by knowing one of the AI Image Editor's event names; grouping by session id gives the same answer.
  • Add durationSeconds to the closing event, measured to when the overlay closes.

Commit 2 — rename the closing event and its counts, so each count says what it was counted from. The event is now AI Image Editor Session, with picturesChosen, picturesApplied, chosenNew, chosenReused and historyItemsAtLaunch. These names are new in 6.5 and haven't shipped, so nothing needs migrating.
