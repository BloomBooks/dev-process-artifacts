What this PR is about

Problem

In the Image Chooser, a Pixabay picture's details panel showed the size of Pixabay's full-size original, often 4000–6000 pixels. The picture Bloom actually puts in the book is much smaller, so it looked as if Bloom had shrunk it far too much on import.

Cause

Bloom downloads Pixabay's largeImageURL. Pixabay scales that image to at most 1280 pixels on its longer side, and offers nothing larger to the kind of API key Bloom users have. The panel was showing the original's dimensions, not those of the file we download.

What the PR does

  • It pins bloom-image-gallery to 40b22f7, the squashed commit of gallery #25 (merged as e15ebfd). In that version, Pixabay pictures report the dimensions of the scaled download, both in the details panel and in the caption under each search result.
  • Pixabay pictures show no file size. Pixabay's CDN doesn't let the browser read the download's size, and the original's size would be wrong.
  • Only the gallery entries in package.json and pnpm-lock.yaml change.
