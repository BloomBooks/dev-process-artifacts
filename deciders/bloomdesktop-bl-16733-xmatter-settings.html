What this PR is about

Problem

The new (React) Collection Settings dialog shows only a placeholder on its Front & Back Matter page. Choosing a front/back matter style, setting up the QR code on the "Made with Bloom" badge, and entering the place names that front matter shows can all still be done only in the old WinForms dialog.

What the PR does

  • Style: a list of the front/back matter packs, with the chosen pack's description beneath it. The dialog's GET carries the packs, says whether the branding chose one (the list is then disabled), and reports the pack the books really get: the factory default if the saved pack has been uninstalled.
  • QR Codes: Show QR Codes and Caption, plus a live preview of the badge that updates as you type, with the language name in bold. It shows the caption as it will be saved, and an empty caption previews the default caption books then get. The badge's language comes from the dialog's values (the sign language, else Language 1). Its QR code is an image from GET collection/qrCode?tag=, made by the same code that puts it in books.
  • Places: Country, Province and District. Config-R doesn't yet show a group's description (sillsdev/config-r#32 adds it), so the page draws the Places heading and explanation itself.

The values were already in the save model, so the save path is unchanged. Page Numbering Style is not on this page; it goes with the Languages page (BL-16739).
