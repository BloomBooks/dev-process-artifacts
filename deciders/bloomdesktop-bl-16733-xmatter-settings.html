What this PR is about

Problem

The new (React) Collection Settings dialog shows only a placeholder on its Front & Back Matter page. Choosing a front/back matter style, setting up the QR code on the "Made with Bloom" badge, and entering the place names that front matter shows can all still be done only in the old WinForms dialog.

What the PR does

  • Style: a list of the front/back matter packs, with the chosen pack's description beneath it. When the branding picks the pack, only that one is listed and the list is disabled. A saved pack that is no longer installed stays in the list, so just viewing the page doesn't change it.
  • QR Codes: Show QR Codes and Caption, plus a live preview of the badge that updates as you type, with the language name in bold. The preview shows the caption the way it will be saved: an empty caption previews the default caption books then get. A new GET collection/qrCodeBadge supplies the QR image, built in memory by the same code that writes it into books, along with the language name, the address the badge shows and the default caption.
  • Places: Country, Province and District. Config-R ignores a group's description, so the page draws the Places heading and its explanation itself.

The values were already in the save model, so the save path is unchanged. Page Numbering Style is not on this page; it goes with the Languages page (BL-16739).
