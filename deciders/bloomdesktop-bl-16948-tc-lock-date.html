What this PR is about

Problem

When someone whose Windows regional format is Thai checks out a book in a Team Collection, every member sees that book's "checked out" date 543 years in the future. Locking and syncing are unaffected; only the date in the status panel is wrong.

Cause

The lock time went into the book's shared status file formatted with the current culture. Thai uses the Buddhist calendar, so the file got 2569-… instead of 2026-….

What the PR does

  • The lock time is now written with the invariant culture, and read back the same way, so it means the same thing on every member's computer.
  • A new test locks under one culture and reads under another, both ways. It fails without the fix.
  • A lock time already written by a Thai computer stays wrong until that book is checked in, which clears it. Until then, Thai members now see it 543 years off as well; they used to see it correctly.
  • Test-only: 9 tests whose Does.Contain / Does.Not.Contain compared with the current culture now compare ordinally, and SubscriptionTests.GetExpirationDate_CalculatesCorrectly formats its expected date invariantly. All now pass under BLOOM_TEST_CULTURE=th-TH. The sweep's other th-TH failures are covered by #8413, #8426 and #8425.

Lock dates already written by a Thai computer

Before this fix, a Thai-format computer that checked out a book wrote a year like 2569 into the shared status file. After the fix, every computer, including the Thai one, reads that value as the real year 2569 and shows it 543 years off. Before, the Thai computer happened to show it correctly. The wrong value lasts only until the book is checked in, which clears it. The next checkout writes a correct date. Only the date in the status panel is affected. Correcting it would mean guessing: treating any year more than about 500 years ahead as Buddhist and subtracting 543. That only covers Thai, and it hides the real value. Given how short-lived the problem is, leaving it seems better. Greptile raised the same point in this thread, which stays open until you decide.
