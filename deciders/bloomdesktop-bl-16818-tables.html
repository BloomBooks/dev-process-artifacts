What this PR is about

Problem

Bloom has no way to lay content out in a grid. Authors who want a vocabulary list with pictures or a simple timetable fake it with positioned text boxes, which drift out of alignment and do not translate as one unit. Tables are a Pro-tier feature, but the people who reuse Pro books, above all to translate them, often have no subscription, so a table has to stay translatable and publishable for them while they are kept from building new ones.

What the PR does

  • Brings in the bloom-table library (grid model, rendering, row, column and cell menus, resizing, its own undo), with Bloom's own cell contents: a Bloom text box, a picture, a video, or a nested table.
  • Offers a table from the Canvas tool palette and as a section type in Change Layout.
  • Gates creating and restructuring tables to Pro and the Tables experiment, with checkboxes in both Settings dialogs; below Pro an existing table stays editable as text.
  • Teaches the shared editing code about tables: Undo order, canvas mouse handling, copy and paste, picture refitting, and the toolbar following a zoom change.
  • In Change Layout mode a table is faded, ignores the mouse, and its section is labelled "Table"; a table on a canvas page cannot be rotated.
  • Adds 43 end-to-end tests across three specs.
