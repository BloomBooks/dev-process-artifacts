What changed

  • Fix BL-14901 — gear icon displaced in Picture on Right page with ebook theme (e798fa17b4). The two ebook appearance themes nudge the edit-mode format cog 20px right so it avoids the page number at the bottom-left — but on landscape “Picture on Right” pages those themes move the page number to the right side, so the nudge just displaced the cog. Each theme now zeroes the nudge for exactly those pages: zero-margin-ebook.css:85 and rounded-border-ebook.css:126. The fix deliberately lives in the theme files, not the shared editMode.less dodge rule, because the EFL migration stylesheets keep their page number bottom-left on such pages and still need their nudge.
