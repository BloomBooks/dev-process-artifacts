What this PR is about

Problem

Many videos in the new Rwandan Sign Language books on Bloom Library don't play. They were recorded as HEVC (H.265), which the Chromium-based players (Bloom Player, WebView2) can't play. Bloom already re-encodes imported sign-language videos to H.264 when they are too large, as these are (720p and 1080p), but its reduced ffmpeg build has no HEVC decoder, so that re-encode fails silently and the video is left as HEVC.

What the PR does

  • Enables ffmpeg's built-in hevc decoder and hevc parser in build/ffmpeg/build-config.sh, which both the x86_64 and arm64 build scripts read. No new library or license file is needed.
  • Updates the size note in BuildingFfmpeg.md: the x86_64 exe grows from about 13MB to about 15MB.

The rebuilt ffmpeg.exe is not in this PR; it goes into lib/ffmpeg separately.
