What this PR is about

Problem

The Booklet Insides PDF for a HalfLetter Landscape book comes out in the wrong page order for the way Bloom tells you to print it. If you follow the Publish tab's instructions (Letter, portrait, flip on long edge, cut horizontally and stack), page 15 ends up on the back of page 1, page 2 on the back of page 16, and so on.

Cause

Bloom chose the cut-and-stack layout only for A5 Landscape. HalfLetter Landscape got the fold layout, which stacks pages for a booklet bound along the top, while the print instructions have always treated HalfLetter Landscape like A5 Landscape.

What the PR does

  • HalfLetter Landscape booklets (insides and cover) now use the cut-and-stack layout: two pages on each portrait Letter sheet.
  • One rule, Book.UsesCutAndStackBooklet, now decides both which layout Bloom makes and whether the Publish tab says "cut and stack", so the two can't disagree again.
  • Nothing changes for any other size. The other landscape sizes still get a top-bound fold booklet; that was deliberately left alone.
