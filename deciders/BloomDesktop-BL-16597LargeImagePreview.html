Your decisions, and what happened

All four carried out; nothing here needs you again.

  • Transparent huge image previews black → composite onto white Done in 72c29597. The stand-in is laid over white before encoding, so see-through areas come out white instead of black. Applied to every stand-in rather than only ones carrying transparency — deciding that reliably means enumerating the pixel formats that can hold alpha and checking indexed palettes, against one pass over an image already capped at 1600px. It is pixel arithmetic, not the WPF rendering stack, so it stays safe on the server's threads. Thread resolved.
  • TIFFs don't preview → fix it here Done in the same commit. The stand-in test widened from size alone to size-or-format, matched on extension because that is what the served content type is derived from. An image already under the preview cap is no longer enlarged. Thread resolved.
  • ImageGalleryApi made IDisposable → keep it Left in place, unchanged.
  • The nine tests the wrapper can't run → log a papercut There was already an entry from 2026-07-15 naming both causes, so it got a dated seen again line rather than a duplicate. It rides along in d784d7f4, per the papercut convention.
  • Three intermittently failing tests → log a papercut Its own entry, in 6a28662f. CheckAudioForAllText_SpansAudioMissing, BringBookUpToDate_MovesMetaDataToJson and InsertPageAfter_FromAnotherBook_CopiesWidget — none near image handling, all passing in isolation. The recorded cost is that a run showing 12 failures can no longer be read at a glance: you have to run the suite twice to tell noise from signal.
  • Rotation geometry untested → leave as is Recorded on the Devin thread, spelling out that reading the tag and swapping width and height are tested across all eight orientations, and that only the transform table's geometry — that 5 is a transpose and 7 a transverse rather than the reverse — rests on two agreeing derivations. Testing it would need WPF types in the test project, which is a build-configuration change better made on its own branch.
