What this PR is about

Problem

A person whose name field is stored as " Ana López " was exported to IMDI as <Name> Ana López </Name> and <FullName> Ana López </FullName>. Since #115 matches that person to their contributions, the spaces reach every session that names them.

What the PR does

  • Every IMDI element that has text is written through one helper, textElement, which trims: field values, computed values, Keys, vocabulary translations and pseudo-session titles.
  • A field value that is only spaces counts as empty, so a required element gets its default.
  • RO-Crate already trimmed every person field. The stored name is left as typed.
