What this PR is about

Five tests have been failing in the nightly e2e run. Each cause below was confirmed from the nightly's trace or by reproducing the failure at the nightly's window size.

(1/5) Text scrolled to the top went under the controls bar (BL-17149)

Problem: 18 inline-image tests could not right-click a block's text in the nightly-sized window. Cause: the controls bar added by All Pages editing (BL-16929) is fixed across the top of the page frame, and the page scrolls under it; a block taller than the window, scrolled into view, has its first line under the bar. Fix (Bloom): the page gets scroll-padding-top the height of the bar, so anything scrolled into view (the caret's line, a focused element) stops below it.

(2/5) A fully scrolled text box looked 2 px short at 150% (BL-17150)

Cause: the helper measured the text from its glyphs, which stand a little above their lines; the box really was at its end. Fix (test): judge the end by the box's own scroll range.

(3/5) New table cells show only L1 now (BL-17158)

Cause: since BL-17105 a new cell shows L1 only, by design; this spec still expected every content language. Fix (test): tick L2 in the column's Languages menu, as tables-extended does.

(4/5) Tests could leave a page before Bloom had its last change (BL-17160)

Cause: a save uses the page's last snapshot, sent a moment after a change; the crop test changed pages 10 ms before the snapshot of its Undo went out. Typing waited for it; Undo, drags and flips did not. Fix (test helpers): goToPage, selectPage and switchTab all wait until Bloom has the page being left (waitForBloomToHavePageAsItIs).

(5/5) The rename test broke on Bloom's own reload (BL-17161)

Cause: Bloom reloads the cover from the renamed folder on purpose (BL-17055), and the poll's read landed mid-reload; the next click could then be refused while the reload finished. Fix (test helpers): wait for the page from the new folder, treat an interrupted read as "not yet" (readUnlessDocumentReplaced), and have selectPage wait for the Edit tab to settle before every click, which also fixed a one-off copy-page failure.

The PR also asks (AGENTS.md, the e2e README, nightly-fix) that each rerun of a failing test get its own --output folder, so a passing rerun cannot delete the failure's trace.
