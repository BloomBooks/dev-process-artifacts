What this PR is about

Problem

In an RO-Crate export, the project's .sprj File entity has a license such as #license-tla-missing, and no entity in the crate has that id. Any project shows it (torture project finding 23).

Cause

File.getTextProperty answers the string "MISSING" for a missing field, so a document with no access field was treated as having the access code "MISSING".

What the PR does

  • One function, getFileAccessValue, reads a file's access value for RO-Crate and treats a missing field as no value; both places that read it use it. Such a document now takes the license of the folder it sits in.
  • New tests export the Edolo sample and check that every referenced license is defined and that the .sprj file gets the root dataset's license.
