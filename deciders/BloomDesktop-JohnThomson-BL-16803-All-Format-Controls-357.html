What this PR is about

Problem

The Format dialog's Characters tab promises that a change made on a text box in the collection's first language applies to the style as a whole, so the same style's boxes in the other languages follow. Every control on that tab kept the promise except Color: a text color chosen on the first-language box changed only that language, and the second-language box beside it kept its old color (BL-16803).

Separately, the manual test "All Format Controls" (Notion test case 357), which walks every control on all four tabs of the dialog and checks where each change lands, had no automated equivalent. Automating it exposed a second gap: creating a new style from a box copied every setting except a font the user had chosen for it, so the text snapped back to the collection's font.

What the PR does

  • Fixes BL-16803. The Color control now writes the color the way bold, size and spacing do: into the language-specific rule always, and into the style's language-independent rule too when the box is in the first language (StyleEditor.ts). Font stays per language, as before.
  • Keeps an explicitly chosen font when a style is created. A box's font normally comes from the collection's language settings, so the new style names a font only when the old style set one for that language, and then per language as the font control writes it, for every language in the box's group. Five unit tests cover the two fixes.
  • Automates Notion test case 357 as all-format-controls.spec.ts: a Basic Book with the three pages the card names, eight text boxes once the second language is on, then every control on every tab, with each change checked on the box at once and then on every box across the pages; changes on a second-language box reach only its four boxes; the Highlighting tab's colors are read back from the Talking Book tool's highlight; a style is created, changed, and applied.
  • Adds the helper layer for the Format dialog's controls, the toolbox handle, the Talking Book highlight, and reading a page's text-box formatting.
