What this PR is about

Problem

Testing the rotate feature from PR #8227, a tester found that on a picture placed over the page (an overlay), a Rotate right survived both Reset Image and Change Image. Reset Image removed the crop and the mirror but left the picture turned, and a replacement picture arrived already turned.

Cause

On an overlay, Rotate right turns the whole box, not the picture inside it. Reset Image, Change Image and paste-to-replace all deliberately left the box's angle alone. An author cannot see that distinction: to them the picture is turned.

What the PR does

  • Reset Image, Change Image, and pasting a picture over an existing one now set the box back to 0 degrees, as well as clearing the picture's own rotation, mirror and crop. This holds whether Rotate right or the rotation handle turned it.
  • Reset Image is offered when only the box is turned.
  • Undo of a picture change brings the old box angle back along with the old picture.
  • After Reset Image, Undo no longer turns the picture back: Reset Image forgets that picture's earlier Rotate right, Flip and handle steps, and keeps an earlier picture change undoable.
