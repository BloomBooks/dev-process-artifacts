What this PR is about

Problem

On a Little Zebra book laid out at Device 16×9 Landscape, the title page’s branding tagline is cut off by the bottom of the page: “Beautiful books for children / in African languages” loses its second line. It is not a regression — it has behaved this way at least since 6.3.

Cause

The Little Zebra title-page branding block holds the wordmark plus that two-line tagline. It is a flex column (from branding-base.less) and the xmatter gives it flex: 0 2 1in, so on a tight title page the flexbox has to shrink it. The logo would not shrink — min-height: auto on a replaced element with a fixed height: 13mm blocks that — so the tagline was the only thing that could give. Its box was squeezed below its own text height and the second line spilled off the page.

What the PR does

Reverses which element yields, in Little-Zebra/branding.less:

  • min-height: 0 on the logo, so the flexbox is allowed to shrink it. object-fit: contain is already inherited from branding-base.less, so it keeps its shape rather than distorting.
  • flex-shrink: 0 on the tagline, so it always keeps both of its lines.

Where there is room, nothing changes — the logo is still exactly 13mm.
