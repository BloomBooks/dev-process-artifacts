What this PR is about

Problem

Bloom is moving narration recordings from MP3 to Opus, which gives much smaller files. Bloom Player always asked for audio/<id>.mp3, so a talking book with Opus narration would play no sound at all.

Cause

The book's HTML identifies each recording only by its element's id, and the player appended .mp3 when it built the file URL.

What the PR does

  • A recorded sentence or text box can now carry data-audio-src, the full name of its file in the book's audio folder (for example data-audio-src="<id>.opus"). The player plays that file. Without the attribute it asks for <id>.mp3, so every existing book behaves exactly as before. Because each recording names its own file, one book can mix formats (narration.ts:1088).
  • The player reads the attribute from the sentence on the current page, because the pages either side stay loaded and can reuse the same ids (narration.ts:1100).
  • A new end-to-end test plays a real Opus narration in the built player, from a small new test book (public/testBooks/opus-talking-book). The test server can now serve .opus and .ogg files.
  • A new root AGENTS.md tells agent workflows which issue tracker this repo uses.

Naming the file in the book was chosen over trying one extension and falling back to the other. A fallback can't tell "wrong extension" from "never recorded", and on Bloom Library every miss costs an extra round trip, which shows up as a longer pause between sentences.

Worth knowing

  • Opus playback is tested end to end in Chrome only. Older Safari versions can't play Ogg Opus, and nothing here tests that.
  • Bloom Desktop still has to write data-audio-src on every recorded element whose file isn't <id>.mp3. Its Talking Book tool also builds .mp3 paths of its own (audioRecording.ts). Until both are done, no real book uses the new path.
  • Your earlier card comment explaining the choice still names data-audio-ext. It's your comment, so it was left alone.
  • Prettier flags narration.ts and e2e/server.mjs for formatting that was already there on master. It was left alone to keep this diff focused.
