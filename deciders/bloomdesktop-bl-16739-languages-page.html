What this PR is about

Purpose

Adds the Languages page to the new React Collection Settings dialog, in place of its placeholder, laid out and worded as the mockup on BL-16739 shows. It brings together the collection's languages, their fonts and their script settings, which the old dialog spreads over its Languages tab, its Book Making tab and the Special Script Settings dialog, and it lets the user edit the reader tools' alphabet and sentence punctuation, which until now only Reader Setup could change.

What the PR does

  • A Languages page with a group each for Written Language 1, 2 and 3 and the Sign Language: Change…, Set…, Remove at the heading, each written language's Default Font, and a More page (Fonts; Language 1's Alphabet; Script, with Language 1's punctuation and the collection's Page Numbering Style).
  • Reader tools, Language 1 only: the alphabet and punctuation are written into the reader tools' own file on OK, keeping its stages; the fields are locked, with a note saying why, while Language 1 is changing or the file is damaged.
  • Saving the languages: each language carries its own font; a removed Language 3 stays, font included, among the collection's other languages.
  • Config-R 1.0.0-alpha.35: heading actions, Markdown descriptions, and number choices in ConfigrSelect (line spacing, tool font size).
  • Number choices follow Bloom's interface language, as the Format dialog's do.
  • run-bloom: the launcher can start the dev server on 5173, which the Edit tab's page list and toolbox need.
