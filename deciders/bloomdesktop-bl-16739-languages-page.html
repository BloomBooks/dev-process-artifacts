What this PR is about

Purpose

Adds the Languages page to the new React Collection Settings dialog, in place of its placeholder, laid out and worded as the mockup on BL-16739 shows. It brings together the collection's languages, their fonts and their script settings, which the old dialog spreads over its Languages tab, its Book Making tab and the Special Script Settings dialog, and it lets the user edit the reader tools' alphabet and sentence punctuation, which until now only Reader Setup could change.

What the PR does

  • A Languages page with a group each for Written Language 1, 2 and 3 and the Sign Language: the language with Change…, Set… for an optional language the collection lacks, and Remove at the right of its heading when it has one; each written language's Default Font; and a More sub-page.
  • The More page follows the mockup: Fonts (Default Font again, tool font size, line spacing), then for Language 1 Other (the Alphabet), then Script (Language 1's sentence ending punctuation, Asian word breaking, right to left, and Language 1's Page Numbering Style).
  • Reader tools, Language 1 only. On OK, just the alphabet and punctuation are written into the reader tools' own file, read again at that moment, keeping the stages and levels; nothing is written if they didn't change. The fields are locked while Language 1 itself is being changed, and when the file is damaged.
  • Saving the languages: each language carries its own font; a removed Language 3 stays, font included, among the collection's other languages.
  • Config-R 1.0.0-alpha.35 (#33 and #34): a control beside a group's heading, Markdown descriptions, and a ConfigrSelect that takes number choices and sits directly on MUI's Select, so the tool font size and line spacing are plain selects whose "Auto" is 0.
