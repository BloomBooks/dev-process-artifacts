What this PR is about

Problem

The new React Collection Settings dialog showed a placeholder on its Languages page. The collection's languages, their fonts and their script settings could only be changed in the old WinForms dialog, spread over its Languages tab, the Book Making tab and the Special Script Settings dialog. The reader tools' alphabet and sentence punctuation could only be changed in Reader Setup.

What the PR does

  • A Languages page with a group each for Language 1, 2, 3 and the Sign Language. Each shows its language with Change…, which opens the existing language chooser as a nested dialog; Language 3 and the Sign Language also offer Set… and Remove. Each written language has its Default Font and a More sub-page with the tool font size, line spacing, Asian word breaking and right-to-left.
  • Reader tools, Language 1 only. Its More page edits the reader tools' alphabet and sentence-ending punctuation. On save, just those two values are written into the reader tools' own file in the collection folder, keeping the stages and levels; nothing is written if they didn't change. The fields are locked while Language 1 itself is being changed, and when the file is damaged, so the rest of the settings always save.
  • Page Numbering Style sits at the bottom of the page. Only its place in the dialog's data moved; the collection file is unchanged.
  • The Front & Back Matter badge preview follows the draft languages. Now that languages can change inside the dialog, the preview names the language the badge will have once saved (the sign language if there is one, else Language 1), not the saved one.
  • Small supporting changes: the settings GET sends the default font for a new Language 3; the language chooser can hand its pick to a callback and is sized properly without a WinForms frame; the reader tools' default settings and alphabet clean-up moved where both callers can use them, unchanged.
