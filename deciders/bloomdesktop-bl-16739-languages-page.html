What this PR is about

Purpose

Adds the Languages page to the new React Collection Settings dialog, in place of its placeholder, laid out and worded as the mockup on BL-16739 shows. It brings together the collection's languages, their fonts and their script settings, which the old dialog spreads over its Languages tab, its Book Making tab and the Special Script Settings dialog, and it lets the user edit the reader tools' alphabet and sentence punctuation, which until now only Reader Setup could change.

What the PR does

  • A Languages page with a group each for Written Language 1, 2 and 3 (each with the mockup's example line) and the Sign Language: the language with Change…, Set… for an optional language the collection lacks, and Remove at the right of its heading when it has one; each written language's Default Font; and a More sub-page.
  • The More page follows the mockup: Fonts (Default Font again, tool font size, line spacing), then for Language 1 Other (the Alphabet), then Script (Language 1's sentence ending punctuation, Asian word breaking, right to left, and Language 1's Page Numbering Style).
  • Reader tools, Language 1 only. On save, just the alphabet and punctuation are written into the reader tools' own file, keeping the stages and levels; nothing is written if they didn't change. The fields are locked while Language 1 itself is being changed, and when the file is damaged. An edited alphabet is cleaned the way Reader Setup cleans it, through a new optional valuesToSave a page can give the dialog.
  • Page Numbering Style stays one setting for the collection, shown on Language 1's More page; the collection file is unchanged.
  • Saving the languages: each language carries its own font, instead of a separate fonts list left over from the old dialog.
  • Config-R 1.0.0-alpha.34 (sillsdev/config-r#33): a control beside a group's heading, a hook for it to change a value, and descriptions rendered as inline Markdown (the bold SURE and KNOW). Every Bloom description that goes through Config-R was checked; they read as before.
