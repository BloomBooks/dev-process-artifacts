What this PR is about

Problem

The Copyright and License dialog looked cramped and uneven. The title was small, the Year and Copyright Holder fields had different gaps below them, and the License tab's choices ran together, which made the long two-line options hard to read.

What the PR does

  • Makes the title larger (20px, medium weight) and gives the dialog wider side margins. Both are set from the dialog itself, because the title component ignores styles passed to it. The margins apply only to the dialog box, not to the full-screen layer behind it.
  • Makes the tab labels slightly larger and letter-spaced, and adjusts the gap between the tabs and the content.
  • Gives the Year and Copyright Holder fields the same 22px gap below them.
  • Restyles the License tab: 14px text with more line height, more space between the choices plus a faint highlight on hover, a gap that sets the "No one can modify…" choice apart from the Creative Commons group, and a smaller grey note above a taller text box for "Other".

Only the styling changes. How copyright and license information is entered, checked and saved is unchanged.
