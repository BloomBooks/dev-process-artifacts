What this PR is about

Problem

The build tools had fallen behind and the checks were not clean: about 590 lint warnings, about 630 unformatted files, and specs, e2e tests and scripts were never type-checked, so the pre-commit hook rejected ordinary merges. Localization ran on Lingui 3 through Babel. On master, strings:extract (which CI's fullbuild runs before packaging) deletes the translations from every non-English fields.po and vocabularies.po, so CI installers can show English field labels in every language. Several e2e tests failed intermittently.

What the PR does

  • Tooling: removes unused ESLint, webpack-era packages, Storybook, tslint, wallaby, patch-package; upgrades TypeScript 7, Playwright 1.64, electron-builder 26.17 (packaging no longer hangs), happy-dom 21, Crowdin CLI 5. Electron stays at 44.
  • Localization: Lingui 6, whose Vite plugin compiles the catalogs into the build; lingui extract can no longer touch fields.po or vocabularies.po; synced with Crowdin V3 after a backup.
  • Checks: specs, e2e and scripts are type-checked; lint is at zero and the hook fails on any warning; every file is formatted (commit listed in .git-blame-ignore-revs); LF line endings.
  • Bugs that lint pointed to: a new person was not saved; a failed delete left the confirm dialog stuck; promises never settled in file copy-in and media stats; failed folder deletions were dropped; "Help translate" called openPath on a URL; several tests asserted nothing.
  • Dead code: removed commented-out UI, including the rules-file chooser, so a previously saved rules file is no longer read.
  • e2e: startup waits for a slow registration dialog (the cause of the flakes); a run stops if src/ or locale/ is newer than dist/.
  • CI: electron-builder signs on macOS again through CSC_LINK.
