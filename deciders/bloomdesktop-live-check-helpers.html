What this PR is about

Purpose

Live-checking the Languages page (#8502) meant writing the same CDP helpers again and again: opening Collection Settings, finding a language group, its More page, a list or a checkbox, the language chooser (with its script step and the hidden copy it leaves behind), Restart, a page in the Edit tab, a reader tool. This keeps them, for agents and for e2e tests, and records what tripped those checks up.

What the PR does

  • E2E helpers to set a language through the chooser and to remove one.
  • A new e2e journey: set Written Language 3 (through the script step) and a sign language, Restart, check the collection file; remove both, Restart, check they are gone.
  • run-bloom driveCollectionSettings.mjs: importable helpers for an agent's live check of the dialog, the chooser, OK/Restart, the Edit tab's page list and the reader tools.
  • run-bloom notes: the Test branding hides page numbers; the interface language reaches the web view only at startup; a problem dialog CDP cannot see; reading user.config without garbling it.
