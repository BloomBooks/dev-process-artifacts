What this PR is about

Problem

lameta runs on Electron 37, which is out of support; Electron 44 is the current stable line. Electron 44 runs Node 24 in the renderer, which removed util.isNullOrUndefined, and no longer gives the renderer Electron's clipboard module. Without changes, the file list fails to render in every folder and the export dialog's "Copy to clipboard" buttons throw.

What the PR does

  • Electron goes from 37.3.0 to 44.9.0 and @electron/remote from 2.1.2 to 2.1.3.
  • The file list's button check uses == null instead of the removed Node function.
  • The export dialog's two "Copy to clipboard" buttons (line 587, line 812) use the browser's navigator.clipboard.
  • Since Electron 42 the binary downloads on first run rather than at install, so postinstall now runs install-electron and the binary arrives during pnpm install as before.
  • The hybrid export cancel test no longer leaves the export dialog open for the next test (waits for the export to start, then closes the dialog). It already failed sometimes on Electron 37; on 44 it failed every time.

Worth knowing

  • The PR pins Electron 44.9.0. Versions 44.9.1 and 44.9.2 came out on 2026-10-20, and pnpm's one-day minimum release age refuses them until tomorrow.
  • @electron/remote is tested upstream only up to Electron 43. On 44 it ran through the whole e2e suite and both launch tests.
  • No e2e test clicks the export dialog's "Copy to clipboard" buttons. The browser clipboard call was checked by hand in an Electron 44 window, and the text reached the Windows clipboard.

Decisions

Electron 44 needs macOS 13 or later

Electron 37 runs on macOS 12 (Monterey); Electron 44 does not. Once this merges, people on macOS 12 can no longer install or run new lameta builds; the versions they already have keep working. Apple stopped security updates for macOS 12 in 2024. Electron 43 still supports macOS 12, but it reaches end of support in early 2027, so staying on it only delays the same cut.

The macOS build has not been tried

Everything was tested on Windows. lameta's macOS release is a universal build that electron-builder 25.1.8 signs and notarizes, and that path only runs on a Mac or in the GitHub Actions workflow, which builds on pushes to V2, beta, release and V3, not on pull requests. A failure there would show up only when a release is cut.
